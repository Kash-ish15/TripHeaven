TripHeaven is a travel-friendly web application where users can explore various travel listings. Registered users can also add listings as hosts, edit them later, and write reviews on different places. The app supports full CRUD functionality for both listings and reviews.
🛠 Tech Stack
Backend: Node.js, Express.js
Frontend: HTML, CSS
Database: MongoDB (with Mongoose ODM)
Authentication: Passport.js
Sessions: express-session with MongoDB session store
Cloud Storage: Cloudinary (for storing listing images)

Features--
 1.RESTful APIs for creating, reading, updating, and deleting (CRUD) listings and reviews.
 2.User Authentication & Authorization using passport-local and session-based login.
 3.Session Management with cookies and MongoDB session storage to maintain login state.
 4.Cloud Image Upload using Cloudinary for storing and accessing listing images efficiently.
 5.Flash Messages & Error Handling for better user experience.
 6.Responsive frontend (with Bootstrap or Tailwind)
